# RFC 语料

这里的 RFC 原文（RFC 9110 / 9112 / 9113 / 7230 / 7231 / 6265 / 1035，约 1.4 MB）
**不进版本库**：它们是公开发布的规范文本，没必要在仓库里存副本。

`intel.py` 需要它们来提取规范性断言。首次使用前跑一次：

```bash
bash engine/blackbox/corpus/fetch.sh
```

下载失败时 `intel.py` 不会崩——它会退回"只有原语库、没有规范断言语料"的模式，
并在输出的 `sources.rfcs_available` 里如实反映为空。**这是降级不是失败**，
但要知道此时"每条原语都能点开 RFC 核对"这个性质就不成立了。
